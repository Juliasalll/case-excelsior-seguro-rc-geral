# Excelsior Seguros · Seguro RC Geral — Landing page (case de portfólio)

Landing page desenvolvida em HTML, CSS e JavaScript puros como **case de portfólio** de **Júlia Sales**, a partir do layout criado no Figma para o produto *Seguro de Responsabilidade Civil Geral* da Excelsior Seguros.

**Site publicado:** https://case-excelsior-julia-sales.netlify.app
**Portfólio (Behance):** https://www.behance.net/DesignerJuliaSales

## O que tem aqui

- `site/`: código completo da landing (HTML, CSS, JS, fontes e imagens).
  - Seções empilhadas com rolagem tipo "folhas" (sticky).
  - Palavras que se revezam no título (`[data-rotate]`).
  - Revelação de texto palavra por palavra e parallax.
  - Responsivo (testado em 390 px e 1920 px), `letter-spacing: 0` nos títulos.

Não há dependências nem etapa de build: abra `site/index.html` ou sirva a pasta `site/` em qualquer hospedagem estática.

## Autoria e uso

Este projeto é um **case fictício de portfólio**. A marca, os textos e as imagens pertencem aos respectivos titulares, e o formulário é apenas demonstrativo.
